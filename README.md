The API returns product information including ID, title, description, price, rating, and thumbnail image.
Required Features
1. Products Listing
Fetch products from the API.
Display product images, titles, and prices in a responsive grid.
Show a loading indicator while fetching data.
Handle API errors gracefully.
2. Search Functionality
Add a search input.
Filter the loaded products by title as the user types.
Display an appropriate message when no products match.
3. Product Details
Navigate to a dedicated product details page using dynamic routing.
Display the product image, title, description, price, and rating.
Support direct navigation to the product details URL.
4. Favorites
Allow users to add or remove products from favorites.
Ensure favorite status remains consistent across the listing and details pages.
Bonus: Persist favorites using localStorage.
5. Responsive Design
Ensure the application works on desktop and mobile screens.
Maintain a clean and usable interface.
